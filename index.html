steps

  1. Plug the XIAO into this computer with a USB-C data cable.
  2. Press a flash button and pick the port named USB JTAG/serial debug unit.
  3. Choose whether to erase. Erasing clears the dog's name, its configuration and its Bluetooth bonds; without it they are kept and only the firmware changes.
  4. Wait for the install to finish. Do not unplug the board while it writes.
  5. Open Drover on the phone and pair the dog from Fleet.

if it does not work

  • no port in the list: hold the BOOT button while plugging the board in, then try again. On Linux your user must be in the dialout or uucp group.
  • port is busy: close any serial monitor that has the port open.
  • wrong chip: this firmware is for the ESP32-C5 only and the flasher refuses any other board.

Flashing runs in your browser with ESP Web Tools (Apache-2.0), served from this site. The firmware goes from this page to the board over USB.
